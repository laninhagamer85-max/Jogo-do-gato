# Assets visuais

A identidade usa um quarto felino ensolarado em tons de madeira e ciano, o gatinho Pudim em ilustração 3D de livro de histórias e HUD azul-marinho translúcido com acentos coloridos. As imagens são originais, criadas para este jogo a partir da referência visual do usuário; os textos de interface são HTML em vez de texto rasterizado.

| Arquivo | Uso | Formato / dimensões |
|---|---|---|
| `src/assets/meu-pet-quarto.webp` | Fundo da cena ortográfica Babylon, sem UI | WebP RGB, 1920×1080 |
| `src/assets/meu-pet-gatinho.webp` | Sprite original do Pudim com transparência | WebP RGBA, 768×768 |

As texturas estão abaixo de 650 KB combinadas e fazem parte do source para que o clone do GitHub rode sem URLs externas de arte.
