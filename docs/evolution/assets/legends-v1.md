# Legends art and prompts

Source reference: user upscalemedia-transformed.png,2048x2022RGBA. Copied unchanged to client/public/forest-adventure/legends/roster-v1.png. Starter identities top-left and bottom-right. Other six reference portraits display future availability only.

Built-in imagegen (not CLI). Transparent output. Each prompt supplied the original full roster as identity reference. Generated PNGs copied unchanged into client/public/forest-adventure/legends/lyra-v1.png and kael-v1.png. No new image files derived by pixel editing. Cell bounding boxes in explorationLegendFrames.json are renderer crop metadata measured from alpha, not image edits.

Lyra prompt: Production game animation spritesheet, transparent background, ONLY female TOP LEFT of reference: long dark hair, brown leather armor with embossed chest emblem, ivory trousers and brown boots, same chibi fantasy illustration identity. Full body. Exactly8columns×8rows evenly spaced, no text/gridlines. Rows south(front), southwest, west, northwest, north(back), northeast, east, southeast. First4columns distinct alternating-foot walk phases with natural arms. Last4columns empty-hand attack anticipation/strike/followthrough/recovery for runtime weapon attachment. Consistent head/body scale and feet baseline, padding, full hair and boots in each cell; no weapons baked in, no backgrounds or ground shadows. True alpha.

Kael prompt: Production game animation spritesheet, transparent alpha. ONLY male BOTTOM RIGHT of reference: short black hair, turquoise scarf, brown leather armor/boots, burgundy shoulder guard, same chibi fantasy identity. Exactly8columns×8rows square uniform cells, no text/gridlines. Facing rows S,SW,W,NW,N,NE,E,SE. Four distinct walk phases then four unarmed attack phases; empty right hand for weapon overlay. Every cell one complete character, same height/centered feet, padding; back views show back of scarf/head. No weapons, background or ground plane.

Inspection: model did not supply a reliable eighth Kael row. Renderer uses existing west/southwest poses mirrored for east/southeast instead of reading blank atlas space. Lyra row spacing and per-cell bounds also differ from ideal grid; explicit measured crop metadata avoids neighbor bleed and normalizes full-body height/feet. This is an initial four-frame illustrated animation set; physical-device/extended play acceptance remains.
